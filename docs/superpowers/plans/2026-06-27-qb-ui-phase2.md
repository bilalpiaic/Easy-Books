# QB Online UI Phase 2 — Token Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Migrate 7 highest-traffic page groups from hardcoded gold/cream hex values to the QB CSS custom-property token system, and introduce a shared `StatusBadge` component.

**Architecture:** Create `StatusBadge.tsx` and a `.qb-card` utility class first (Task 1), then run targeted `sed` bulk-replacement commands per page group (Tasks 2–8), manually handle the few exceptions that sed can't reach (chart JS strings, statusColors dict removal), verify build after every task, and commit.

**Tech Stack:** Next.js 16 App Router, React 19, TypeScript, Tailwind CSS v4, lucide-react, GNU sed (available on WSL2 Linux).

## Global Constraints

- **Zero logic changes** — only `className` strings, one JS color array, and one statusColors dict change per task.
- **Zero backend changes.**
- **`npm run build` must pass** after every task before committing. Run from `frontend/`.
- **PRA dark banner** in `invoices/page.tsx` keeps `bg-[#1a1814]` — it is an intentional high-contrast UI element, not a brand token. The sed commands below do NOT replace `bg-[#1a1814]`, only `text-[#1a1814]` and `border-[#1a1814]`.
- **All sed commands** run from the repo root: `/home/mbilal71/projects/Easy-Books`.
- **Existing `.ui-th` / `.ui-td` classes** in `globals.css` (lines 68–69) handle density spacing only — do not modify them.

```typescript
"use client"

import { cn } from "@/lib/utils"

const BADGE: Record<string, { bg: string; fg: string }> = {
  paid:       { bg: "var(--badge-green-bg)",  fg: "var(--success)" },
  posted:     { bg: "var(--badge-green-bg)",  fg: "var(--success)" },
  active:     { bg: "var(--badge-green-bg)",  fg: "var(--success)" },
  delivered:  { bg: "var(--badge-green-bg)",  fg: "var(--success)" },
  completed:  { bg: "var(--badge-green-bg)",  fg: "var(--success)" },
  sent:       { bg: "var(--badge-yellow-bg)", fg: "#D97706" },
  due:        { bg: "var(--badge-yellow-bg)", fg: "#D97706" },
  partial:    { bg: "var(--badge-yellow-bg)", fg: "#D97706" },
  pending:    { bg: "var(--badge-yellow-bg)", fg: "#D97706" },
  received:   { bg: "var(--badge-yellow-bg)", fg: "#D97706" },
  overdue:    { bg: "var(--badge-red-bg)",    fg: "var(--danger)" },
  void:       { bg: "var(--badge-red-bg)",    fg: "var(--danger)" },
  rejected:   { bg: "var(--badge-red-bg)",    fg: "var(--danger)" },
  draft:      { bg: "var(--badge-gray-bg)",   fg: "var(--text-muted)" },
  inactive:   { bg: "var(--badge-gray-bg)",   fg: "var(--text-muted)" },
  cancelled:  { bg: "var(--badge-gray-bg)",   fg: "var(--text-muted)" },
  processing: { bg: "var(--badge-blue-bg)",   fg: "var(--text-link)" },
  info:       { bg: "var(--badge-blue-bg)",   fg: "var(--text-link)" },
  approved:   { bg: "var(--badge-purple-bg)", fg: "#7C3AED" },
}

const FALLBACK = { bg: "var(--badge-gray-bg)", fg: "var(--text-muted)" }

export default function StatusBadge({
  status,
  className,
}: {
  status: string
  className?: string
}) {
  const { bg, fg } = BADGE[status?.toLowerCase()] ?? FALLBACK
  return (
    <span
      className={cn(
        "px-2.5 py-0.5 rounded-full text-[11px] font-bold uppercase tracking-wide",
        className
      )}
      style={{ backgroundColor: bg, color: fg }}
    >
      {status}
    </span>
  )
}
```
